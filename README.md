is drawn from reporting published that day; see `SOURCES.txt`.

## Run it

```sh
python3 main.py
```

The entrypoint writes the image to `/output/entry.png`. main.py uses only the Python standard library to copy the pre-rendered image; Pillow is needed only locally to rebuild via make_image.py. No network access.
